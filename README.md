# Arunima Mustyala

Basic static website built with:

- HTML
- CSS
- JavaScript

There is no React, npm, framework, database, or build step.

## View the website

Opening `index.html` inside a code editor shows the HTML source. To render the website, run this command from the repository folder:

```powershell
python -m http.server 4173
```

Then open [http://localhost:4173](http://localhost:4173).

## Main files

- `index.html` — homepage
- `assets/css/styles.css` — all styling
- `assets/js/` — navigation, forms, and interactions
- `assets/images/` — temporary images
- Other folders contain the linked HTML pages

Common clinic details can be changed in `assets/js/site-config.js`.

Forms are demonstrations only and do not send information.
